    How it works

    Games see real input
    Keys go out as hardware scan codes and clicks as raw mouse events, the way DirectInput and Raw Input games read them.
    Your trigger stays yours
    The key that starts the macro is caught before the game and never reaches it. Use a side mouse button, a function key, anything but left click.
    Nothing stays pressed
    Every press is paired with its release. Quitting, or restarting after a crash, lets go of anything still held.

    Before you run it

    Games running as administrator
    Windows blocks input from a normal program to an elevated one. Right-click MacroClic.exe and choose Run as administrator.
    A SmartScreen warning
    The exe isn't signed, and it reads and sends input, so Windows or your antivirus may ask first. The full source is on GitHub.
    Your settings
    Saved the moment you change them, in %APPDATA%\MacroClic. Press Esc while choosing a key to cancel.

    Build it yourself

    Python 3.13 on Windows, one dependency. The commands are in the README. Pushing a version tag builds the exe on GitHub Actions and publishes it as a release.
